# Portable Spacewise для Windows

Распакуйте ZIP в собственную папку и запустите `Spacewise.Desktop.exe`. Установщик и .NET Runtime отдельно не нужны. Маркер `portable.flag` рядом с exe включает portable-режим; для обычной сборки можно использовать `--portable`.

БД, ключи, настройки, исключения, логи, загружаемые модели и карантин находятся в подпапке `Data`. Существующие данные установленной версии из `%LOCALAPPDATA%\Spacewise` автоматически не переносятся. Windows может сохранять собственные сведения о запуске программы.

При первом запуске задайте пароль не короче 12 символов. Он защищает переносимый ключ БД через PBKDF2-SHA256 и AES-256-GCM. Пароль не сохраняется. При следующих запусках вводите тот же пароль. Неверный пароль не сбрасывает ключ или БД. Потерянный пароль восстановить нельзя; храните резервную копию `Data`.

Настройки, список исключений, файлы карантина и журналы не получают дополнительного шифрования этим паролем: пароль защищает ключи SQLite-БД. Обычная установленная версия продолжает использовать DPAPI. Для автоматической проверки можно передать пароль через переменную окружения процесса `SPACEWISE_PORTABLE_PASSWORD`; не храните его в скриптах рядом с приложением.

Файлы выбранных категорий удаляются безвозвратно после подтверждения. Если в данных уже есть файлы от старых сборок, их можно отдельно вернуть или удалить из прежнего карантина. Корзина Windows очищается окончательно после отдельного предупреждения. При пользовательских исключениях эта категория недоступна.

Исключения вводятся на вкладке анализа по одному абсолютному пути на строку и сохраняются при запуске сканирования или предпросмотра очистки. Они проверяются снова перед очисткой. Повреждённый файл исключений блокирует запуск вместо молчаливого снятия защиты.

Сборка:

```powershell
./installer/build-portable.ps1
```

Проверка ZIP в этой рабочей среде не заменяет запуск на чистой Windows или на другом компьютере. Карантин с другого компьютера содержит исходные абсолютные пути: для восстановления они должны существовать и быть доступны.
