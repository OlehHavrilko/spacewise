# Spacewise — состояние и план Windows

Актуально на 9 ноября 2026. Исходники и скрипты сборки соответствуют Windows 0.4.0. Публичный установщик доступен в [релизе 0.3.0](https://github.com/OlehHavrilko/spacewise/releases/tag/v0.3.0). Дальнейшая разработка сосредоточена на Windows. Linux-сборка остаётся доступной из исходников.

## Что уже работает

| Область | Текущая Windows-сборка |
| --- | --- |
| Анализ | Сканирование метаданных с отменой и обозначением неполного охвата, крупнейшие файлы, дерево и карта папок, сравнение итогов по тому же корню, история томов и тренды папок. Поиск дубликатов BLAKE3 показывает группы без действий удаления. Есть HTML-отчёт и экспорт с отдельным включением путей. |
| Каталог | 57 встроенных правил с файловыми фикстурами, проверка занятости, предпросмотр, ручной выбор категорий и постоянные исключения. Пользовательские правила JSON проходят те же проверки путей и исключений. [Формат правил](USER_RULES.md) |
| Очистка | После подтверждения файлы выбранных категорий удаляются напрямую. Перед операцией проверяются FileId, том, размер, время изменения и исключения. Для файлов старых сборок предусмотрены действия с прежним карантином. Очистка системной Корзины подтверждается отдельно и недоступна при заданных исключениях. |
| Программы | Инвентарь Win32 и Steam. Деинсталляция MSI по коду продукта или запуск зарегистрированного EXE в папке установки. После проверки записи Windows просматриваются зарегистрированная папка и точные совпадения издателя и программы в AppData и ProgramData. Общие папки исключаются. Для отдельного файла из точного совпадения в пользовательском AppData доступно прямое удаление после подтверждения и повторной проверки. |
| Интерфейс и история | WPF с боковой навигацией, русским интерфейсом и темами. Результат отделяет логический размер от изменения свободного места на томе. Есть журнал решений, локальная отметка о последствиях и восстановление состояния прерванного плана. |
| Помощник | Необязательная локальная модель объясняет категории и подсказывает, что проверить у выбранного файла или среди возможных остатков. Файлы представлены условными номерами, размерами и подсказками по известным расширениям. [Провайдеры](ASSISTANT_PROVIDERS.md) |
| Поставка | WiX MSI и portable ZIP с отдельным каталогом данных и паролем для ключа БД. Публичный MSI 0.3.0 использует прямое удаление и подписан самоподписанным сертификатом. [Portable](PORTABLE.md) |

## Что проверено

- Windows 11 x64, .NET SDK 10.0.403. Release-сборка и 368 автоматических тестов прошли. Проверены границы поиска остатков, прямое удаление тестовых файлов и раскрытая панель остатков при ограничениях в DIP.
- Скрипт `tests/Verify-WindowsUninstall.ps1` проверил установку и деинсталляцию отдельного MSI для текущего пользователя, поиск и удаление оставленного файла. Соседний контрольный файл сохранился. Проверка выполнена на машине разработки.
- Установщик Spacewise 0.4.0 прошёл аудит таблиц WiX. Приложение запустилось из административной распаковки MSI. Распакованный portable ZIP запустился дважды с тем же ключом базы. Лицензии и процесс локального ИИ присутствуют в обоих пакетах. Пакеты кандидата собраны без доверенной подписи.
- Linux x64. Свежая self-contained сборка прошла 17 из 17 тестов под обычным пользователем Ubuntu 24.04 в WSL2 и графический запуск через Xvfb. Особенности сборки и ограничения описаны отдельно. [Linux](LINUX.md)
- Локальный помощник ранее проходил проверку в Vulkan и CPU-режиме. Модель загружается отдельно по согласию пользователя.

## Следующие шаги

1. **Расширить матрицу деинсталляции.** На чистой VM прогнать разные штатные EXE, отмену и обязательную перезагрузку. Дополнить инвентарь и деинсталляцию MSIX и штатными сценариями лаунчеров. Поддержка таких форматов остаётся отдельным этапом.
2. **Довести интерфейс Windows.** Пройти реальный сеанс с 125/150/200% DPI, высоким контрастом, клавиатурой и Narrator. Начать с боковой навигации, списка программ, панели остатков и подтверждений. Проверить полный путь файловой очистки на временных файлах и двух томах, включая отмену, изменение файла после предпросмотра, прерывание и измерение освобождённых байтов. Довынести общие пользовательские строки Core/Catalog в ресурсы там, где они видны в интерфейсе.
3. **Измерить поведение на реальном диске.** Замерить холодный и тёплый старт, сканирование и предпросмотр на одном воспроизводимом наборе, включая большие деревья и недоступные папки. Зафиксировать время, память, задержку отмены и блокировки UI. Цели из ТЗ — первый экран до 3 с, отмена до 500 мс, отсутствие работы UI-потока дольше 100 мс. Добавлять ограниченный параллелизм или инкрементальное сканирование после профилирования.
4. **Проверить публичный выпуск Windows.** На чистой Windows 11 x64 проверить обычную установку MSI, обновление поверх 0.3.0 и удаление с сохранением данных. Windows 10 включать в матрицу поддержки после отдельного прогона 22H2. Выбрать способ доверенной подписи и опубликовать контрольные суммы вместе с пакетом.

После стабилизации Windows можно отдельно брать расширение каталога с фикстурами, более точное сравнение снимков, уведомления, качество и производительность помощника, подпись обновлений и брокер для системных операций. Детальные требования и критерии приёмки остаются в [ТЗ](spec/ТЗ%20Spacewise.md), технические решения — в [ADR](adr/).
