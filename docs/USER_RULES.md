# Пользовательские правила JSON

Каталоги загружаются из подпапки `rules` в каталоге данных приложения. Linux перечитывает их при предпросмотре; Windows — при запуске. Не более 32 файлов, 1 МиБ на файл, 128 правил на файл. ID должны быть уникальными во всех наборах. Ошибка разбора блокирует загрузку вместо частичного принятия опасного набора.

Наборы не содержат исполняемого кода. Подписи сообщества и автоматического обновления пока нет. Не устанавливайте правила из источника, которому не доверяете. Пользовательские категории не выбираются автоматически и помечаются как непроверенные. На Windows они принудительно получают риск Expert, последствие Lost и запрет автоматического выбора. Системная защита и исключения сохраняют приоритет.

## Linux

```json
{
  "version": 1,
  "rules": [{
    "id": "custom.mytool",
    "title": "Мой инструмент: временные сборки",
    "directory": "mytool/build-cache",
    "minimumAgeDays": 30,
    "include": ["**/*.tmp"],
    "consequences": "Проверьте назначение файлов; удаление может потребовать повторной сборки."
  }]
}
```

`directory` — фиксированная относительная папка внутри XDG_CACHE_HOME. Нельзя указать абсолютный путь, `..`, ссылку или glob в корне. `include` — относительные шаблоны с `/`; `*` и `?` не переходят через разделитель, `**` переходит. Сопоставление учитывает регистр. По умолчанию include равен `["**"]`.

## Windows

Используется существующая схема `src/Spacewise.Catalog/catalog.json`: `version`, `rules`, `ruleVersion`, `detect`, `targets`, описания последствий и fixture-метаданные обязательны. Корни — из разрешённых переменных `%USERPROFILE%`, `%LOCALAPPDATA%`, `%APPDATA%`, `%TEMP%`, `%SYSTEMROOT%`; glob использует `\\`. Доступно только действие `delete`, которое приложение выполняет через карантин. Наличие fixture-метаданных в чужом JSON не означает, что приложение выполнило или подтвердило эти проверки.

Версия набора независима от версии приложения. Автоматический импорт CCleaner/BleachBit пока отсутствует: их команды и ограничения нельзя считать эквивалентными этой схеме.
